## Portfolio

- Meatguy Steakhouse marketing and creative campaigns
- Dims The Meatguy content strategy and production
- Other creative work, with separate long-form and short-form galleries
- Professional experience, education, awards, and contact details
- 22 videos linked from YouTube and Google Drive
- Cinematic intro, scroll animation, metric counters, and reduced-motion support

## Run locally

No dependencies or build step are required. The images are embedded in `index.html`.

```sh
python3 -m http.server 8000
```

Open http://localhost:8000. For deployment, serve this repository root over HTTPS.

Videos load after a visitor selects a thumbnail. Each player includes an original-source link. Playback follows the video provider’s access and browser settings.
